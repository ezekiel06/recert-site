# Attest support

- **Documentation**: this site and the in-app help text.
- **Questions and bug reports**: open an issue at
  <https://github.com/ezekiel06/attest-site/issues>.
- **Security issues**: use GitHub's private vulnerability reporting on the same repository
  ("Security" tab → "Report a vulnerability") rather than a public issue.
- **Response target**: two business days.
